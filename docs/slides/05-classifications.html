Pipeline d’entraînement

  1. Préparer les données (normalisation)
  2. Partager : entraînement / validation / test
  3. Apprendre le modèle (hyper-paramètres)
  4. Valider (régler les hyper-paramètres)
  5. Tester sur des données indépendantes

Construction d’un ensemble d’entraînement

  • On échantillonne une carte déjà classifiée (carte.tif, 12 classes)
  • N points aléatoires par classe (ex. 100) évite un jeu trop déséquilibré
  • Chaque point est relié à ses valeurs radiométriques via les coordonnées géoréférencées
  • Le résultat (position + classe + bandes) est sauvegardé en .csv, réutilisé par tous les classificateurs
import rasterio
img_carte = rxr.open_rasterio('../carte.tif', mask_and_scale=True).squeeze()

pts, cls = [], []
for c in range(1, 13):                      # 12 classes d'occupation du sol
    pix = np.argwhere(img_carte.data == c)
    n = min(100, len(pix))
    idx = np.random.RandomState(0).choice(len(pix), n, replace=False)
    pts.extend(pix[idx]); cls.extend([c]*n)
pts = np.array(pts)
print("Points échantillonnés :", pts.shape[0], "sur", len(np.unique(cls)), "classes")

transformer = rasterio.transform.AffineTransformer(img_carte.rio.transform())
xy = transformer.xy(pts[:, 0], pts[:, 1])
with rasterio.open('../RGBNIR_of_S2A.tif') as src:
    valeurs = [v for v in src.sample(list(zip(*xy)))]
print("Valeurs de bandes du premier point :", valeurs[0])

Analyse préliminaire des données

Avant d’entraîner un modèle : dimensions, nombre de classes, échantillons/classe, séparabilité.

  • Hypothèse gaussienne multivariée par classe : centre \(m_i\), covariance \(\Sigma_i\)
  • Distance de Jeffries-Matusita (JM), basée sur la distance de Bhattacharyya \(B\) [@Jensen2016]
  • \(JM_{ij} = 2(1-e^{-B_{ij}})\) : proche de \(2\) → classes bien séparées, proche de \(0\) → confusion probable
  • Guide le choix des bandes/indices les plus discriminants
def bhattacharyya(m1, s1, m2, s2):
    s = (s1 + s2) / 2
    d = m1 - m2
    t1 = d @ np.linalg.inv(s) @ d / 8
    t2 = 0.5*np.log(np.linalg.det(s) / np.sqrt(np.linalg.det(s1)*np.linalg.det(s2)))
    return t1 + t2

def jm(m1, s1, m2, s2):
    return 2*(1 - np.exp(-bhattacharyya(m1, s1, m2, s2)))

from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis as QDA
q = QDA(store_covariance=True).fit(Xtr, ytr)
print("JM(classe 0, classe 1) =", round(jm(q.means_[0], q.covariance_[0], q.means_[1], q.covariance_[1]), 3))
JM(classe 0, classe 1) = 1.944

Méthode des parallélépipèdes

La plus simple des méthodes non paramétriques : une boîte par classe.

  • Bornes [min, max] de chaque bande, classe par classe
  • Un pixel est assigné si toutes ses bandes tombent dans la boîte
  • Rapide, mais laisse des trous et des recouvrements entre classes
bornes = {c: (Xtr[ytr == c].min(0), Xtr[ytr == c].max(0)) for c in np.unique(ytr)}
c0 = np.unique(ytr)[0]
print("Nombre de classes :", len(bornes))
print("Boîte de la classe", c0, "- min :", bornes[c0][0].round(1))
Nombre de classes : 10
Boîte de la classe 0 - min : [1264. 1430. 1274. 2167.]

La malédiction de la haute dimension

  • Densité de points \(\propto N / d^D\) : chute exponentielle avec le nombre de dimensions \(D\)
  • Les parallélépipèdes deviennent creux : l’espace vide croît plus vite que les données
  • Contre-mesures : sélection de caractéristiques, réduction de dimension (ACP)
d, N = 10, 1000   # N points dans un hypercube de côté d
for D in [1, 2, 5, 10, 20]:
    print(f"D={D:2d} -> densité ~ {N / d**D:.2e}")

Distances et plus proche voisin

Le K-NN repose sur des distances : cdist les calcule toutes, argmin donne le plus proche voisin — identique à scikit-learn pour \(K = 1\).

from scipy.spatial.distance import cdist
from sklearn.preprocessing import StandardScaler

sc = StandardScaler().fit(Xtr)
D = cdist(sc.transform(Xte), sc.transform(Xtr))    # (n_test, n_train)
y_ppv = ytr[D.argmin(axis=1)]                       # plus proche voisin
print("Matrice des distances :", D.shape)
print("Exactitude 1-PPV « à la main » :", round((y_ppv == yte).mean(), 3))
Matrice des distances : (200, 800)
Exactitude 1-PPV « à la main » : 0.39

Méthodes par arbre de décision

  • Cascade de règles de seuil sur chaque bande [@Breiman1984]
  • Frontières de décision en escaliers (hyper-rectangles)
  • Tendance au sur-apprentissage, surtout si peu d’échantillons par dimension
  • max_depth contrôle directement la complexité de l’arbre
from sklearn.tree import DecisionTreeClassifier
for prof in [2, 5, None]:
    arbre = DecisionTreeClassifier(max_depth=prof, random_state=0).fit(Xtr, ytr)
    print(f"profondeur={prof} - exactitude test : {arbre.score(Xte, yte):.3f}")

Méthode Bayésienne naïve

  • Modèle gaussien par classe, bandes supposées indépendantes
  • Calcul rapide : peu de paramètres à estimer
  • Frontières de décision plus régulières que le K-NN
  • Base simplifiée dont l’ADQ relâche l’hypothèse d’indépendance
from sklearn.naive_bayes import GaussianNB
gnb = GaussianNB().fit(Xtr, ytr)
print("Bayésien naïf - exactitude test :", round(gnb.score(Xte, yte), 3))
Bayésien naïf - exactitude test : 0.345

Analyse discriminante quadratique (ADQ)

  • Généralise le Bayésien naïf : covariance complète par classe (bandes non indépendantes)
  • Chaque classe = une ellipse (gaussienne multivariée) dans l’espace des bandes
  • Plus de paramètres à estimer → exige davantage de données par classe
  • Sert aussi à mesurer la séparabilité JM (voir plus haut)
from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis as QDA
qda = QDA(store_covariance=True).fit(Xtr, ytr)
print("ADQ - exactitude test :", round(qda.score(Xte, yte), 3))
ADQ - exactitude test : 0.38

Analyse post-classification — bilan surfacique

Points clés

  • Classification supervisée = classe par pixel à partir d’un jeu étiqueté
  • Entraînement / validation / test pour détecter le sur-apprentissage
  • Performance via la matrice de confusion (rappel, précision, f1)
  • Non paramétriques (parallélépipèdes, K-NN, arbres) vs paramétriques (Bayésien, ADQ) vs MLP
  • La malédiction de la dimensionnalité guide le choix de réduire la dimension (ACP)
  • Le K-NN repose sur des distances (cdist) ; après coup, bincount donne le bilan surfacique par classe
