La transformée de Fourier

import numpy as np, matplotlib.pyplot as plt
N, Fs = 16, 2.0; Ts = 1/Fs
t = np.arange(0, N, Ts)
sig = np.sin(2*np.pi*t*4/16)                 # 4 périodes sur 16
F = np.fft.fft(sig); freq = np.fft.fftfreq(F.size, d=Ts)
fig, ax = plt.subplots(1, 2, figsize=(7, 2.7))
ax[0].plot(t, sig, 'r.-'); ax[0].set_title("Signal périodique")
ax[1].plot(freq, np.abs(F), 'r.-'); ax[1].set_title("Composantes de Fourier")
plt.show()

Filtrage fréquentiel

  • Passe-bas : ne garde que les basses fréquences → lissage
  • Passe-haut : ne garde que les hautes fréquences → détails/contours
  • Passe-bande : une bande de fréquences précise
  • Filtrer = multiplier le spectre par la réponse du filtre
import rioxarray as rxr
from scipy import ndimage
img = rxr.open_rasterio('../berkeley.jpg').to_numpy()        # (3, H, W)
spectre = np.fft.fft2(img)
lisse = [ndimage.fourier_gaussian(spectre[b], sigma=4) for b in range(3)]
lisse = np.fft.ifft2(lisse).real
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].imshow(img.transpose(1,2,0).astype('uint8')); ax[0].set_title("Originale"); ax[0].axis('off')
ax[1].imshow(lisse.transpose(1,2,0).astype('uint8')); ax[1].set_title("Passe-bas gaussien (Fourier)"); ax[1].axis('off')
plt.show()

from scipy.ndimage import gaussian_filter

Filtrage d’image

  • Objectifs : réduire le bruit, réhausser, extraire des caractéristiques
  • Global (Fourier) vs local (fenêtre glissante)
  • Linéaire (moyenne, convolution) vs non linéaire
  • Stationnaire vs adaptatif

Filtrage linéaire stationnaire — filtre moyen

Un filtre moyen remplace chaque pixel par la moyenne de son voisinage → réduit le bruit, adoucit les détails.

from scipy.ndimage import uniform_filter
gris = img[0]                                    # une bande
lisse3 = uniform_filter(gris, size=5)            # moyenne sur une fenêtre 5x5
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].imshow(gris, cmap='gray'); ax[0].set_title("Originale"); ax[0].axis('off')
ax[1].imshow(lisse3, cmap='gray'); ax[1].set_title("Filtre moyen 5x5"); ax[1].axis('off')
plt.show()

Filtrage par convolution — contours (Scharr)

Un filtre de gradient (Scharr) met en valeur les contours — les fortes variations locales :

from scipy import signal
scharr = np.array([[-3-3j, 0-10j, 3-3j], [-10+0j, 0+0j, 10+0j], [-3+3j, 0+10j, 3+3j]])
gris = img[0]                                    # une bande
grad = np.abs(signal.convolve2d(gris, scharr, boundary='symm', mode='same'))
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].imshow(gris, cmap='gray'); ax[0].set_title("Originale"); ax[0].axis('off')
ax[1].imshow(grad, cmap='gray'); ax[1].set_title("Contours (Scharr)"); ax[1].axis('off')
plt.show()

Filtrage non linéaire — filtre médian

  • Un filtre non linéaire ne s’exprime pas comme une simple pondération des voisins
  • Le filtre médian remplace chaque pixel par la médiane locale
  • Élimine le bruit impulsionnel (sel et poivre) en préservant mieux les contours qu’un filtre moyen
from scipy.ndimage import median_filter, uniform_filter
bruite = img.astype(float).copy()
masque_bruit = np.random.random(bruite.shape) < 0.05
bruite[masque_bruit] = np.random.choice([0, 255], size=masque_bruit.sum())
moyen = uniform_filter(bruite, size=(1, 5, 5))
median = median_filter(bruite, size=(1, 5, 5))
fig, ax = plt.subplots(1, 3, figsize=(9, 3))
for a, im, titre in zip(ax, (bruite, moyen, median), ("Bruitée", "Filtre moyen", "Filtre médian")):
    a.imshow(im.transpose(1, 2, 0).astype('uint8')); a.set_title(titre); a.axis('off')
plt.tight_layout(); plt.show()

Morphologie mathématique — ouverture

  • Opère sur des masques binaires par opérateurs ensemblistes : érosion, dilatation
  • L’ouverture (érosion puis dilatation) élimine les petits objets clairs isolés
  • Utile pour nettoyer un masque issu d’un seuillage ou d’une segmentation
from skimage.morphology import opening, disk
sar = rxr.open_rasterio('../SAR.tif').sel(band=1)
sar = sar.where(sar > 0)                          # masque no_data
sar_db = np.log10(sar.to_numpy())
masque = sar_db > np.percentile(sar_db, 75)       # 25 % des pixels les plus intenses
masque_ouvert = opening(masque, disk(2))
fig, ax = plt.subplots(1, 2, figsize=(7, 3.5))
ax[0].imshow(masque, cmap='gray'); ax[0].set_title("Masque original"); ax[0].axis('off')
ax[1].imshow(masque_ouvert, cmap='gray'); ax[1].set_title("Après ouverture"); ax[1].axis('off')
plt.tight_layout(); plt.show()

Gestion des bordures

Une fenêtre glissante déborde aux bords ; il faut décider quoi faire des pixels manquants.

  • Ignorer (nan) → l’image de sortie rétrécit
  • Miroir (reflect, mirror) → prolonge par symétrie
  • Constante (constant) ou réplication du bord (nearest)
from scipy.ndimage import uniform_filter
fig, ax = plt.subplots(1, 3, figsize=(9, 3))
for a, mode in zip(ax, ['reflect', 'constant', 'nearest']):
    a.imshow(uniform_filter(img[0], size=15, mode=mode), cmap='gray')
    a.set_title(f"bordure : {mode}"); a.axis('off')
plt.show()

Du filtre à la couche convolutionnelle

Une couche convolutionnelle applique des filtres comme celui de Scharr — mais dans un réseau de neurones, ces filtres sont appris à partir des données.

import torch, torch.nn as nn
conv = nn.Conv2d(1, 1, kernel_size=3, padding=1, bias=False)   # une couche conv 3x3
scharr_gx = torch.tensor([[-3., 0, 3], [-10, 0, 10], [-3, 0, 3]]).reshape(1, 1, 3, 3)
conv.weight = nn.Parameter(scharr_gx)                          # noyau imposé (Scharr Gx)
x = torch.tensor(gris, dtype=torch.float32)[None, None]        # (1, 1, H, W)
sortie = conv(x)[0, 0].detach().numpy()
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].imshow(gris, cmap='gray'); ax[0].set_title("Entrée"); ax[0].axis('off')
ax[1].imshow(np.abs(sortie), cmap='gray'); ax[1].set_title("Sortie — couche conv (Scharr)"); ax[1].axis('off')
plt.show()

Ici le noyau est imposé ; un CNN l’apprendrait par rétro-propagation (tome 2).

Filtrage adaptatif — le speckle SAR

Les images radar sont dégradées par un bruit multiplicatif (speckle). Le filtre de Lee lisse en préservant les détails (pondération selon la variance locale) :

\[ I_F = I_M + K(I - I_M), \qquad K = \frac{\sigma^2_I}{\sigma^2_I + \sigma^2_{bruit}} \]

moy = sar.rolling(x=5, y=5, min_periods=3, center=True).mean()
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
np.log10(sar).plot.imshow(ax=ax[0], add_colorbar=False); ax[0].set_title("SAR brut (speckle)"); ax[0].axis('off')
np.log10(moy).plot.imshow(ax=ax[1], add_colorbar=False); ax[1].set_title("Filtre moyen 5x5"); ax[1].axis('off')
plt.show()

Texture — matrice de co-occurrence (GLCM)

  • Capture comment les niveaux de gris varient spatialement, au-delà des contours
  • La GLCM compte les paires de valeurs voisines pour une direction/distance donnée
  • On en dérive contraste, homogénéité, énergie, corrélation
  • Distingue des surfaces de radiométrie semblable mais de texture différente (forêt vs champ)
from skimage.feature import graycomatrix, graycoprops
from skimage.util import img_as_ubyte
from skimage.color import rgb2gray
gris_tex = img_as_ubyte(rgb2gray(img.transpose(1, 2, 0) / 255.0))
fenetre_a = gris_tex[:80, :80]     # coin supérieur gauche
fenetre_b = gris_tex[-80:, -80:]   # coin inférieur droit
for nom, fenetre in [("Fenêtre A", fenetre_a), ("Fenêtre B", fenetre_b)]:
    glcm = graycomatrix(fenetre, distances=[1], angles=[0], levels=256, symmetric=True, normed=True)
    props = {p: round(graycoprops(glcm, p)[0, 0], 3) for p in ("contrast", "homogeneity", "energy", "correlation")}
    print(nom, props)
Fenêtre A {'contrast': np.float64(410.179), 'homogeneity': np.float64(0.114), 'energy': np.float64(0.016), 'correlation': np.float64(0.869)}
Fenêtre B {'contrast': np.float64(572.694), 'homogeneity': np.float64(0.085), 'energy': np.float64(0.015), 'correlation': np.float64(0.821)}

Segmentation en super-pixels — SLIC

SLIC regroupe les pixels en régions homogènes et compactes (couleur + distance) :

from skimage.segmentation import slic, mark_boundaries
rgb = img.transpose(1, 2, 0).astype('uint8')      # berkeley (réutilisée)
seg = slic(rgb, n_segments=250, compactness=10, sigma=1, start_label=1)
fig, ax = plt.subplots(figsize=(5, 3.6))
ax.imshow(mark_boundaries(rgb, seg))
ax.set_title(f"SLIC — {len(np.unique(seg))} super-pixels"); ax.axis('off')
plt.show()

Quick Shift

  • Segmentation par recherche de mode (ascension de gradient), pas de k-moyennes itératives
  • Pas besoin de fixer le nombre de segments à l’avance
  • kernel_size : échelle spatiale · max_dist : distance de fusion maximale
  • ratio équilibre couleur vs position — un rôle analogue au poids \(m\) de SLIC
from skimage.segmentation import quickshift
segments_qs = quickshift(rgb, kernel_size=5, max_dist=10, ratio=0.5)
fig, ax = plt.subplots(1, 2, figsize=(8, 3.6))
ax[0].imshow(mark_boundaries(rgb, seg)); ax[0].set_title(f"SLIC ({len(np.unique(seg))} segments)"); ax[0].axis('off')
ax[1].imshow(mark_boundaries(rgb, segments_qs)); ax[1].set_title(f"Quick Shift ({len(np.unique(segments_qs))} segments)"); ax[1].axis('off')
plt.show()

Fusion des segments — graphe d’adjacence (RAG)

  • La sur-segmentation est fréquente → fusionner les segments similaires en post-traitement
  • Un graphe d’adjacence de régions (RAG) relie les segments qui se touchent
  • On fusionne les nœuds de couleur moyenne proche jusqu’à un seuil
from skimage import graph, color
def poids_couleur(graph, src, dst, n):
    diff = graph.nodes[dst]['mean color'] - graph.nodes[n]['mean color']
    return {'weight': np.linalg.norm(diff)}

def fusion_couleur(graph, src, dst):
    graph.nodes[dst]['total color'] += graph.nodes[src]['total color']
    graph.nodes[dst]['pixel count'] += graph.nodes[src]['pixel count']
    graph.nodes[dst]['mean color'] = graph.nodes[dst]['total color'] / graph.nodes[dst]['pixel count']

g = graph.rag_mean_color(rgb, seg)
print("Segments avant fusion :", len(g))
fusionne = graph.merge_hierarchical(seg, g, thresh=20, rag_copy=False, in_place_merge=True,
                                     merge_func=fusion_couleur, weight_func=poids_couleur)
print("Segments après fusion :", len(g))

avant = color.label2rgb(seg, rgb, kind='avg', bg_label=0)
apres = color.label2rgb(fusionne, rgb, kind='avg', bg_label=0)
fig, ax = plt.subplots(1, 2, figsize=(8, 3.6))
ax[0].imshow(mark_boundaries(avant, seg)); ax[0].set_title("Avant fusion"); ax[0].axis('off')
ax[1].imshow(mark_boundaries(apres, fusionne)); ax[1].set_title("Après fusion"); ax[1].axis('off')
plt.show()

Points clés

  • La transformée de Fourier : point de vue fréquentiel réversible ; passe-bas avant de décimer pour éviter l’aliasing
  • Convolution = filtrage local linéaire efficace (moyenne, Scharr)
  • Filtre non linéaire (médian, morphologie mathématique) ≠ pondération des voisins
  • Lee : filtre adaptatif contre le speckle SAR
  • Texture (GLCM) : contraste, homogénéité, énergie, corrélation
  • SLIC / Quick Shift + RAG + regionprops : de l’image aux objets
