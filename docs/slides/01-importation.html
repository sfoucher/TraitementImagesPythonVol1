Importation et manipulation d’images

Chapitre 1 — Traitement d’images satellites avec Python

Foucher, Apparicio, Bouroubi, Germain, Clabaut

Objectifs

  • Connaître les bibliothèques Python pour lire une image
  • Accéder aux métadonnées avant de la lire
  • Comprendre les formats (RVB vs géo-formats)
  • Manipuler la matrice de pixels avec numpy
  • Exploiter la géoréférence avec rioxarray / xarray

Quatre caractéristiques d’une image

  1. Matrice de pixels — le cube de données (NumPy)
  2. Dynamique — le type de stockage (uint8, int16, float32…)
  3. Nombre de bandes — de 3 (RVB) à des centaines (hyperspectral)
  4. Métadonnées — dimensions, date, et surtout la géoréférence

Deux familles de formats

  • GDAL regroupe la plupart des formats matriciels (ses drivers)
  • RVB (JPEG, PNG) : au plus 3 bandes, 8 bits (uint8), peu de métadonnées
  • Géo-formats (GeoTIFF, HDF5, NetCDF) : multi-bandes, 16 bits/float, géoréférencés
  • RVB → vision par ordinateur (OpenCV, PyTorch) ; géo-formats → télédétection

Lire un format RVB — trois bibliothèques

  • PIL : Image.open() — affichage direct, peu de métadonnées
  • OpenCV : cv2.imread() — retourne un tableau NumPy, mais en BGR
  • Rasterio : lit aussi le RVB, avec avertissement d’absence de géoréférence
import cv2, matplotlib.pyplot as plt
img_bgr = cv2.imread('../modis-aqua.PNG')
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)   # BGR -> RGB
fig, ax = plt.subplots(1, 2, figsize=(7, 3.2))
ax[0].imshow(img_bgr); ax[0].set_title("Sans conversion (BGR)"); ax[0].axis('off')
ax[1].imshow(img_rgb); ax[1].set_title("Après conversion (RGB)"); ax[1].axis('off')
plt.show()

Le format GeoTIFF

  • Extension du TIFF intégrant des métadonnées géospatiales
  • Origine : JPL/NASA, années 1990 — standard de facto en télédétection/SIG
  • Supporte plus de 3 bandes, tant qu’elles ont la même dimension
  • Standardisé par l’OGC en 2019 (GeoTIFF 1.1)

Cloud Optimized GeoTIFF (COG)

  • Variante du GeoTIFF conçue pour l’accès HTTP distant
  • Permet de lire une partie du fichier sans le télécharger en entier
  • Particulièrement utile pour les applications infonuagiques

Découpage (slicing) et vue vs copie

  • Syntaxe matrice[début:fin:pas], comme pour les listes Python
  • matrice[ligne, colonne, bande] : indices commençant à 0
  • Par défaut, un découpage crée une vue (même mémoire), pas une copie
import numpy as np
img_col = img[:, 2, :]                        # troisième colonne, toutes les bandes
print("Vue partagée :", np.shares_memory(img, img_col))
copie = img_col.copy()                        # force une copie indépendante
print("Copie partagée :", np.shares_memory(img, copie))
Vue partagée : True
Copie partagée : False

Démo — lecture et vraies couleurs

L’ordre des bandes de RGBNIR_of_S2A.tif est B, V, R, PIR → on réordonne en R, V, B :

Indexation avancée — bande dominante

argmax sur l’axe des bandes → la bande la plus brillante en chaque pixel :

import numpy as np
cube = rxr.open_rasterio('../RGBNIR_of_S2A.tif').to_numpy()   # (4, H, W) ; B,V,R,PIR
dominante = cube.argmax(axis=0)                               # 0..3
fig, ax = plt.subplots(figsize=(5, 3.6))
im = ax.imshow(dominante, cmap='viridis'); ax.axis('off')
ax.set_title("Bande dominante (0=B, 1=V, 2=R, 3=PIR)")
fig.colorbar(im, ax=ax, ticks=[0, 1, 2, 3], shrink=0.7); plt.show()

Le PIR domine sur la végétation. Renvoie toujours une copie (contrairement au découpage).

Rapport de bandes — le NDVI

Combiner deux bandes pixel par pixel met en valeur un thème (ici la végétation) :

img = rxr.open_rasterio('../RGBNIR_of_S2A.tif').astype('float32')   # B,V,R,PIR
ndvi = (img.sel(band=4) - img.sel(band=3)) / (img.sel(band=4) + img.sel(band=3))
fig, ax = plt.subplots(figsize=(4.6, 3.2))
ndvi.plot.imshow(vmin=-0.2, vmax=0.8, cmap='RdYlGn', ax=ax)
ax.set_title("NDVI = (PIR - R) / (PIR + R)"); ax.axis('off'); plt.show()

Masquer les pixels non valides — np.ma

Exclure des pixels (no data, nuages, eau) d’un calcul statistique :

rouge, pir = img.sel(band=3).to_numpy(), img.sel(band=4).to_numpy()
ndvi_np = (pir - rouge) / (pir + rouge)
ndvi_veg = np.ma.masked_where(ndvi_np < 0, ndvi_np)      # exclut eau/bâti (NDVI < 0)
print("Pixels valides :", ndvi_veg.count(), "/", ndvi_np.size)
print("NDVI moyen (tous)       :", round(float(ndvi_np.mean()), 3))
print("NDVI moyen (végétation) :", round(float(ndvi_veg.mean()), 3))

NDVI moyen (tous)       : 0.48
NDVI moyen (végétation) : 0.486

Exporter un résultat — rio.to_raster

La façon la plus directe d’écrire un DataArray en GeoTIFF, géoréférence conservée :

img_rvb = img.sel(band=[1, 2, 3])          # 3 premières bandes (B, V, R)
img_rvb.rio.to_raster('rgb.tif')
print("Image exportée :", tuple(img_rvb.sizes.values()))

Écrire un GeoTIFF depuis un tableau NumPy — rasterio

Sauver un tableau calculé en héritant le profil (CRS, transform) de l’image source :

import rasterio
with rasterio.open('../RGBNIR_of_S2A.tif') as src:
    rouge, pir = src.read(3).astype('float32'), src.read(4).astype('float32')
    profil = src.profile                        # hérite CRS, transform, dimensions
ndvi = (pir - rouge) / (pir + rouge)
profil.update(count=1, dtype='float32')         # une bande, en float
with rasterio.open('ndvi.tif', 'w', **profil) as dst:
    dst.write(ndvi, 1)                           # GeoTIFF géoréférencé

Créer une géoréférence de toutes pièces — from_origin

Sans image source, on construit la transformation affine à partir du coin supérieur gauche :

from rasterio.transform import from_origin
donnee = np.random.default_rng(0).random((100, 100)).astype('float32')
transform = from_origin(500000, 5000000, 10, 10)   # origine (x, y) + pixel de 10 m
with rasterio.open('synthetique.tif', 'w', driver='GTiff', height=100, width=100,
                   count=1, dtype='float32', crs='EPSG:32618', transform=transform) as dst:
    dst.write(donnee, 1)
print("Raster synthétique écrit :", donnee.shape, "| pixel 10 m, EPSG:32618")
Raster synthétique écrit : (100, 100) | pixel 10 m, EPSG:32618

Sauvegarder un tableau NumPy — .npy / .npz

Stockage temporaire (sans géoréférence) d’un résultat intermédiaire :

Découpage — clip_box

Extraire une emprise plus petite (boîte englobante, dans le CRS de l’image) :

img = rxr.open_rasterio('../RGBNIR_of_S2A.tif')
minx, miny, maxx, maxy = img.rio.bounds()
cx, cy = (minx + maxx) / 2, (miny + maxy) / 2
dx, dy = (maxx - minx) / 4, (maxy - miny) / 4
sous = img.rio.clip_box(cx - dx, cy - dy, cx + dx, cy + dy)
print("forme :", tuple(img.sizes.values()), "->", tuple(sous.sizes.values()))
fig, ax = plt.subplots(figsize=(4.5, 3))
sous.sel(band=[3, 2, 1]).plot.imshow(vmin=86, vmax=5000, ax=ax)
ax.set_title("Quart central"); ax.axis('off'); plt.show()
forme : (4, 1926, 2074) -> (4, 964, 1038)

Rééchantillonnage — reproject

Changer la résolution spatiale ; méthode d’agrégation au choix (moyenne pour réduire) :

from rasterio.enums import Resampling
bas = img.rio.reproject(img.rio.crs, resolution=20, resampling=Resampling.average)
print("résolution :", img.rio.resolution(), "->", bas.rio.resolution())
print("forme      :", tuple(img.sizes.values()), "->", tuple(bas.sizes.values()))

forme      : (4, 1926, 2074) -> (4, 963, 1037)

Reprojection cartographique — reproject

Changer de système de coordonnées ; rioxarray recalcule la grille et la géoréférence :

print("CRS d'origine :", img.rio.crs)            # EPSG:32618 (UTM)
img_wgs84 = img.rio.reproject("EPSG:4326")        # -> latitude / longitude
print("Après reprojection :", img_wgs84.rio.crs)
print("Nouvelle forme :", dict(img_wgs84.sizes))

Après reprojection : EPSG:4326
Nouvelle forme : {'band': 4, 'y': 1633, 'x': 2483}

Pourquoi xarray ?

  • Les données géoscience sont riches en métadonnées (dates, coordonnées, unités…)
  • xarray ajoute étiquettes, dimensions et attributs aux tableaux NumPy
  • Opérations sur des dimensions nommées, pas des numéros d’axe
  • Diffusion (broadcasting) et alignement de type base de données

DataArray et Dataset

  • DataArray : un tableau étiqueté — values, dims, coords, attrs, name
  • Dataset : conteneur de plusieurs DataArray alignés — dims, data_vars, coords, attrs
  • Les deux supportent les opérations de type dictionnaire et conservent les métadonnées

Sélection par étiquette — sel / isel

xarray sélectionne par valeur (sel) ou par position (isel) ; on peut nommer les bandes :

print("sel(band=4) == isel(band=3) :", bool((img.sel(band=4) == img.isel(band=3)).all()))
img_n = img.assign_coords(band=['B', 'V', 'R', 'PIR'])
print("bande PIR par étiquette :", img_n.sel(band='PIR').shape)
sel(band=4) == isel(band=3) : True
bande PIR par étiquette : (1926, 2074)

Un calcul entre bandes (NDVI) renvoie un DataArray qui conserve la géoréférence.

Données vectorielles — GeoPandas

  • Vecteur = points / lignes / polygones + attributs (shapefile, GeoPackage, GeoJSON)
  • GeoPandas = pandas + une colonne géométrie (GeoDataFrame)
  • read_file lit même une archive .zip ; .crs porte la géoréférence
  • Se filtre exactement comme un DataFrame
import geopandas as gpd
ad = gpd.read_file('../AD_Sherbrooke.zip')      # aires de diffusion de Sherbrooke
print(len(ad), "entités |", ad.crs)
print("denses (>3000 hab/km2) :", int((ad['HabKm2'] > 3000).sum()))
333 entités | EPSG:3347
denses (>3000 hab/km2) : 100

Cartographier un GeoDataFrame

  • Choroplèthe statique : .plot(column=…, scheme='quantiles')
  • Reprojection to_crs('EPSG:4326') pour les fonds de carte web

import matplotlib.pyplot as plt

Points clés

  • GDAL = lecture/écriture de l’imagerie (drivers de formats)
  • RVB (au plus 3 bandes, 8 bits) vs géo-formats (GeoTIFF, COG, géoréférence)
  • Consulter les métadonnées avant de lire (rio info, gdalinfo, rasterio)
  • Une image est un tableau NumPy — découpage, vue vs copie
  • Indexation avancée (argmax), tableaux masqués (np.ma), sauvegarde (.npy/.npz)
  • Écrire un GeoTIFF : rio.to_raster, profil rasterio hérité, ou géoréférence construite (from_origin)
  • rioxarray / xarray : DataArray/Dataset, dimensions nommées + géoréférence via .rio
  • Découper (clip_box), rééchantillonner/reprojeter (reproject), sélectionner par étiquette (sel/isel)
  • Données vectorielles : geopandas (GeoDataFrame), requêtes attributaires, choroplèthe (.plot), carte interactive (leafmap)
