Qu’est-ce que l’information spectrale ?

  • Dimension spectrale : le long des bandes de l’image
  • 4–5 bandes (très haute résolution spectrale) → une quinzaine (multispectral) → centaines (hyperspectral)
  • La signature spectrale caractérise le type et l’état d’un matériau
  • Une généralisation de la couleur au-delà du visible
  • Base USGS de signatures de laboratoire [@Kokaly-2017]

Indices spectraux

  • Mettent en valeur des caractéristiques du spectre (pentes, gradients)
  • Améliorent la séparabilité de certaines classes
  • Le choix dépend fortement de l’application
  • spyndex (Awesome Spectral Indices) : 200+ indices (optiques et radar)

Le NDVI

L’indice le plus connu, à partir du rouge (\(R\)) et du proche-infrarouge (\(N\)) :

\[ NDVI = \frac{N - R}{N + R} \]

  • Végétation dense → NDVI élevé (proche de 1)
  • Eau, sol nu, bâti → valeurs faibles voire négatives

SAVI et EVI

\[ EVI = G \times \frac{N - R}{N + C_1 \times R - C_2 \times B + L} \]

  • SAVI : facteur de correction du sol (\(L\)) pour un couvert clairsemé
  • EVI : corrige en plus l’effet de l’atmosphère via la bande bleue (\(B\)) [@Jensen2016]
  • Limite la saturation du NDVI sur la végétation dense
  • Constantes usuelles : \(G=2{,}5\), \(C_1=6\), \(C_2=7{,}5\), \(L=1\)

Réduction de dimension

  • Ne retenir que l’information principale d’un jeu de données
  • Objectifs : réduire le bruit, faciliter la visualisation (3 bandes)
  • Le degré d’information ≈ la variance (contraste) d’une bande
  • L’ACP range l’information en ordre de variance décroissante

Produit matriciel — transformation linéaire

  • Nouvelle bande = somme pondérée des bandes d’origine
  • Mêmes poids pour tous les pixels → un produit matriciel (@)
  • L’ACP apprend ces poids automatiquement (plutôt que de les fixer)
pixels = np.array([[10., 40.], [20., 10.], [5., 25.]])   # 3 pixels x 2 bandes
M = np.array([[0.5, 0.5],       # moyenne des deux bandes
              [1.0, -1.0]])      # différence des deux bandes
print(pixels @ M.T)             # (3 pixels x 2 sorties)
[[ 25. -30.]
 [ 15.  10.]
 [ 15. -20.]]

Transformation Tasseled Cap (Kauth-Thomas)

  • Transformation linéaire à coefficients fixes (Crist 1985, Landsat TM) [@Jensen2016; @richards2022remote; @Schowengerdt2007]
  • Trois composantes interprétables : brillance, verdure, humidité
  • Appliqués ici, à titre d’illustration, aux bandes Sentinel-2 analogues
  • Coefficients fixes → comparables entre scènes (contrairement à l’ACP)
tc_coeffs = np.array([
    [ 0.3037,  0.2793,  0.4743,  0.5585,  0.5082,  0.1863],   # Brightness
    [-0.2848, -0.2435, -0.5436,  0.7243,  0.0840, -0.1800],   # Greenness
    [ 0.1509,  0.1973,  0.3279,  0.3406, -0.7112, -0.4572],   # Wetness
])
tc_bands = ["B", "G", "R", "N", "S1", "S2"]
X_tc = img_s2.sel(band=tc_bands).data.reshape(len(tc_bands), -1)
brightness, greenness, wetness = (tc_coeffs @ X_tc).reshape(3, *img_s2.shape[1:])
fig, ax = plt.subplots(ncols=3, figsize=(9, 3.5))
for a, im, t in zip(ax, (brightness, greenness, wetness), ("Brightness", "Greenness", "Wetness")):
    a.imshow(im); a.set_title(t); a.axis('off')
plt.tight_layout(); plt.show()

ACP — variance expliquée

  • On aplatit le cube (bandes × pixels), puis on centre les données
  • On diagonalise la matrice de covariance (np.linalg.eigh)
  • Valeurs propres = variance portée par chaque composante
cube = img_s2.to_numpy()
B, H, W = cube.shape
X = cube.reshape(B, H * W).T
X_c = X - X.mean(axis=0)
valeurs, vecteurs = np.linalg.eigh(np.cov(X_c, rowvar=False))
ordre = np.argsort(valeurs)[::-1]
valeurs, vecteurs = valeurs[ordre], vecteurs[:, ordre]
ratio = valeurs / valeurs.sum()
print("Variance expliquée (5 premières) :", ratio[:5].round(3))
Variance expliquée (5 premières) : [0.829 0.121 0.032 0.01  0.002]

ACP — composantes principales

  • Projection des pixels sur les vecteurs propres = un produit matriciel
  • Composantes rangées par variance décroissante
  • 3 premières composantes ≈ l’essentiel de l’information
composantes = (X_c @ vecteurs).T.reshape(B, H, W)
etirer = lambda x: (x - x.min()) / (x.max() - x.min())
fig, ax = plt.subplots(figsize=(4.5, 4))
ax.imshow(np.dstack([etirer(composantes[i]) for i in range(3)]))
ax.set_title("Composantes 1-2-3 (RVB)"); ax.axis('off'); plt.show()

Reconstruction et erreur de compression

  • Garder les \(k\) premières composantes = compresser l’image
  • Reconstruction = projection inverse + ajout de la moyenne
  • Erreur mesurée par le RMSE en fonction de \(k\) [@richards2022remote]
def erreur_reconstruction(k):
    proj_k = composantes[:k].reshape(k, -1).T
    X_approx = proj_k @ vecteurs[:, :k].T + X.mean(axis=0)
    return np.sqrt(np.mean((X - X_approx) ** 2))
erreurs = [erreur_reconstruction(k) for k in range(1, B + 1)]
fig, ax = plt.subplots(figsize=(5, 3.5))
ax.plot(range(1, B + 1), erreurs, 'o-')
ax.set_xlabel("Composantes conservées (k)"); ax.set_ylabel("RMSE"); ax.grid(True)
plt.show()

Au-delà de l’ACP : MNF et ICA

  • L’ACP suppose des données gaussiennes et classe par variance décroissante
  • MNF (Minimum/Maximum Noise Fraction) : classe par rapport signal/bruit décroissant — utile en hyperspectral bruité [@richards2022remote]
  • ICA (composantes indépendantes) : relâche l’hypothèse gaussienne, cherche des composantes statistiquement indépendantes

Points clés

  • La signature spectrale caractérise le type/état d’un matériau
  • Un indice met en valeur le spectre et améliore la séparabilité
  • spyndex : 200+ indices, nomenclature de bandes (N, R, G…)
  • NDVI \(=(N-R)/(N+R)\) ; SAVI/EVI corrigent respectivement le sol et l’atmosphère
  • Une transformation linéaire de bandes = un produit matriciel ; Tasseled Cap (coefficients fixes) et ACP (coefficients appris) en sont deux exemples
  • La reconstruction tronquée quantifie la perte d’information selon le nombre de composantes conservées
