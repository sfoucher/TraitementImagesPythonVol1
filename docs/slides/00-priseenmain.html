Quatre structures de base

  • Liste […] — ordonnée, modifiable, doublons permis
  • Tuple (…) — ordonné, immuable
  • Ensemble {…} — non ordonné, sans doublons
  • Dictionnaire {clé: valeur} — paires étiquetées

Listes

bandes = ["bleu", "vert", "rouge", "PIR"]
print(bandes[0], "|", bandes[-1], "|", bandes[1:3])   # index, tranche
bandes.append("SWIR")
print([b.upper() for b in bandes])                    # compréhension de liste
bleu | PIR | ['vert', 'rouge']
['BLEU', 'VERT', 'ROUGE', 'PIR', 'SWIR']

Tuples

  • (…) — ordonné mais immuable (non modifiable après création)
  • Idéal pour des données qui ne doivent pas changer (paramètres, dimensions)
  • Permet les doublons, comme une liste
dimensions = (512, 512)          # immuable : dimensions d'une image
lignes, colonnes = dimensions    # dépaquetage
print(lignes, colonnes)
# dimensions[0] = 1024   # -> TypeError : un tuple est immuable
512 512

Ensembles (sets)

  • {…} — non ordonné, sans doublons
  • Utile pour dédupliquer et faire des opérations ensemblistes (&, |)
classes = ["eau", "forêt", "eau", "urbain", "forêt"]
print(set(classes))                          # doublons éliminés

a, b = {1, 2, 3}, {3, 4}
print("intersection :", a & b, "| union :", a | b)
{'forêt', 'urbain', 'eau'}
intersection : {3} | union : {1, 2, 3, 4}

Dictionnaires

image = {"capteur": "Sentinel-2", "bandes": 13, "resolution_m": 10}
image["date"] = "2024-07-01"                 # ajout d'une paire
for cle, valeur in image.items():
    print(f"{cle} : {valeur}")
capteur : Sentinel-2
bandes : 13
resolution_m : 10
date : 2024-07-01

Dictionnaires — * et **

** déballe les paires clé-valeur ; * ne déballe que les clés.

image = {"capteur": "Sentinel-2", "bandes": 13}
def resume(capteur, bandes):
    return f"{capteur} : {bandes} bandes"

print(resume(**image))              # ** : paires -> arguments nommés
print([*image])                     # * : les clés seules
print({**image, "date": "2024"})    # fusion de dictionnaires
Sentinel-2 : 13 bandes
['capteur', 'bandes']
{'capteur': 'Sentinel-2', 'bandes': 13, 'date': '2024'}

Compréhensions : liste & dictionnaire

Construire une collection en une ligne — [expression for x in itérable if condition].

bandes = ["bleu", "vert", "rouge", "PIR"]
print([b.upper() for b in bandes if len(b) <= 4])    # liste (avec filtre)
print({nom: i for i, nom in enumerate(bandes)})       # dictionnaire
print({c for c in ["eau", "eau", "sol"]})             # ensemble (sans doublon)
['BLEU', 'VERT', 'PIR']
{'bleu': 0, 'vert': 1, 'rouge': 2, 'PIR': 3}
{'sol', 'eau'}

Fonctions

def ndvi(nir, rouge):
    """NDVI = (PIR - Rouge) / (PIR + Rouge)."""
    return (nir - rouge) / (nir + rouge)

print(round(ndvi(0.6, 0.2), 3))
0.5

Le NDVI reviendra au chapitre 3 — ici c’est juste l’occasion d’introduire def/return.

Programmation objet

  • Classe = plan ; objet = instance avec attributs et méthodes
  • Encapsulation — cache les détails internes
  • Héritage — une classe hérite d’une autre
  • Polymorphisme — un même message, une réponse propre à chaque objet
class Image:
    def __init__(self, capteur, bandes):   # constructeur + attributs
        self.capteur = capteur
        self.bandes = bandes
    def resume(self):                       # méthode
        return f"{self.capteur} — {self.bandes} bandes"

print(Image("Landsat-8", 11).resume())
Landsat-8 — 11 bandes

Exécutable — le plus simple

Un fichier .py lancé depuis un terminal ; le code utile va dans __main__.

# ndvi.py
import rioxarray as rxr
if __name__ == "__main__":
    img  = rxr.open_rasterio("RGBNIR_of_S2A.tif")
    ndvi = (img.sel(band=4) - img.sel(band=3)) / (img.sel(band=4) + img.sel(band=3))
    ndvi.rio.to_raster("ndvi.tif")
python ndvi.py          # ou ./ndvi.py après un chmod +x

Un avant-goût de NumPy

Une image = une matrice de nombres (ndarray), la brique de tous les chapitres.

import numpy as np
image = np.array([[10, 12, 11,  9],
                  [ 8, 20, 22,  7],
                  [ 9, 21, 23,  8]])
print("Forme :", image.shape, "| max :", image.max(), "| moyenne :", image.mean().round(2))
print(image[:2, :2])          # découpage d'une sous-image
Forme : (3, 4) | max : 23 | moyenne : 13.33
[[10 12]
 [ 8 20]]

NumPy — type et attributs

Une matrice se décrit par sa forme et son type (dtype), qui encode la profondeur radiométrique.

import numpy as np
image = np.array([[10, 12, 11, 9], [8, 20, 22, 7], [9, 21, 23, 8]])
print("dtype :", image.dtype, "| ndim :", image.ndim, "| size :", image.size)

# uint8 (0-255) vs float32 (réflectance) : conversion avec astype
reflectance = (image / image.max()).astype("float32")
print("nouveau dtype :", reflectance.dtype)
dtype : int64 | ndim : 2 | size : 12
nouveau dtype : float32

NumPy — le broadcasting

Une opération s’applique à toute la matrice sans boucle : NumPy « étire » les formes compatibles.

image = np.array([[10, 12, 11, 9], [8, 20, 22, 7], [9, 21, 23, 8]])

# scalaire : convertir des comptes numériques en réflectance
print("scalaire :", (image / 10000).round(4)[0])

# par bande : un gain différent par bande via une forme (bandes, 1, 1)
cube = np.stack([image, image * 3])            # 2 bandes
gains = np.array([1.0, 0.5]).reshape(2, 1, 1)
print("par bande :", (cube * gains)[:, 0, 0])
scalaire : [0.001  0.0012 0.0011 0.0009]
par bande : [10. 15.]

NumPy — remodeler et réordonner

reshape change la forme ; transpose réordonne les axes — l’idiome du pipeline de classification.

cube = np.stack([image, image * 3])            # (2, 3, 4) = (bandes, lignes, colonnes)
print("cube  :", cube.shape)
print("HWC (pour l'affichage)  :", cube.transpose(1, 2, 0).shape)          # (3, 4, 2)
print("table pixels x bandes   :", cube.transpose(1, 2, 0).reshape(-1, 2).shape)  # (12, 2)
cube  : (2, 3, 4)
HWC (pour l'affichage)  : (3, 4, 2)
table pixels x bandes   : (12, 2)

transpose(1,2,0) + reshape(-1, bandes) = l’entrée exacte d’un classificateur (chapitre 5).
